# Sign-Up Form
A one page sign up for an arbitrary website. A project to design a standard sign up page.<br>
This project is part of the requirement to complete the [The Odin Project](https://www.theodinproject.com)

## Features
the sign up has the following features
- Required Email and password 
- HTML & CSS validation
- UI element for great user experience
- Built for web client on PC

## Objectives
1. to demonstrate skill in creating HTML forms
2. to demonstrate skill in basic form styling
3. to demonstrate skills in using customs fonts
4. to demonstrate skills in styling through complex selectors, psuedo-elements and pseudo-classes
5. to demonstrate skill in form validation using HTML & CSS only
6. Showcase best-pratices in form creation and validation

## Technology Used
- HTML5
- CSS3
